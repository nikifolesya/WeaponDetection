# Weapon Detection System

## Описание проекта
Weapon Detection System — это веб-приложение для обнаружения оружия на изображениях и видео. Система использует модель машинного обучения, предоставленную через Roboflow API, для анализа загруженных файлов. Результаты детекции отображаются в виде аннотированных изображений или видео, а также сохраняются в истории. Пользователь может экспортировать отчёты в формате PDF или Excel.

---

## Функциональность
- Загрузка изображений и видео для анализа.
- Обнаружение оружия с использованием модели YOLO (yolo-weapon-detection/2).
- Отображение результатов детекции с аннотациями.
- Ведение истории загруженных файлов и результатов.
- Генерация отчётов в формате PDF и Excel.
- Визуализация статистики обнаружений и типов загруженных файлов.

## Установка и запуск

### 1. Клонирование репозитория
Склонируйте проект на ваш локальный компьютер:
```bash
git clone https://github.com/nikifolesya/WeaponDetection.git
cd WeaponDetection
```

### 2. Создание виртуального окружения
Создайте и активируйте виртуальное окружение:
```bash
python3 -m venv .venv
source .venv/bin/activate  # Для Linux/MacOS
.venv\Scripts\activate     # Для Windows
```

### 3. Установка зависимостей
Установите все необходимые библиотеки:
```bash
pip install -r requirements.txt
```

### 4. Настройка API-ключа Roboflow
Создайте файл .env в корне проекта и добавьте ваш API-ключ Roboflow:
```bash
ROBOFLOW_API_KEY=your_roboflow_api_key
```

### 5. Запуск приложения
Запустите Flask-сервер:
```bash
flask run
```

Приложение будет доступно по адресу: http://127.0.0.1:5000
